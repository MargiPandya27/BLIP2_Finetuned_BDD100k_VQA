🚗 BDD100K Risk Assessment VQA GeneratorThis project transforms the BDD100K driving dataset labels into a Visual Question Answering (VQA) dataset focused on driving safety and risk assessment. It uses geometric principles (Pinhole Camera Model) to estimate the distance to the front vehicle and combines this with traffic signal data to generate safety decisions and accompanying rationales.🚀 How It Works: The Core LogicThe system is built around three main steps: Context Extraction, Decision Making, and Rationale Generation.1. Context Extraction (Distance Estimation)The VehicleDistanceEstimator class uses a simplified Pinhole Camera Model to calculate the distance to a detected vehicle without explicit camera calibration.Formula Used:The core principle is that the real-world size of an object is proportional to its image size, scaled by the focal length and distance:$$Z = \frac{K \cdot W_{real}}{w}$$ParameterCode VariableAssumed ValueDescription$Z$distance_combinedEstimated Distance (in meters).$K$assumed_focal_length$1000$ pixelsAssumed camera focal length.$W_{real}$avg_vehicle_width/height$1.8 \text{ m}/1.5 \text{ m}$Assumed average real-world size of a vehicle.$w$bbox_width/heightVehicle size in image pixels.Filtering for the Front Vehicle:The find_closest_vehicle function ensures relevance by selecting the vehicle that is both:The closest object.Centrally located (within $10\%$ of the image center), filtering out vehicles in adjacent lanes.2. Proximity ClassificationThe estimated distance ($Z$) is classified into one of three risk levels using defined thresholds:ProximityDistance RangeThreshold ConstantClose$Z \le 8.0 \text{ m}$CLOSE_DISTANCE_THRESHOLD_MMedium$8.0 \text{ m} < Z \le 25.0 \text{ m}$MEDIUM_DISTANCE_THRESHOLD_MFar$Z > 25.0 \text{ m}$3. Decision Logic (decide_answer)The classified proximity and the detected traffic light color determine the final safety recommendation:Hazard DetectedResulting AnswerTraffic Light is Red OR Vehicle is CloseNo (Stop)Traffic Light is Yellow OR Vehicle is Mediumslow_downTraffic Light is Green AND Vehicle is Far or NoneYes (Proceed)📝 Example VQA OutputEach item generated by the script includes the original image path, a randomly selected question, the reasoned answer, and the metadata used for the decision.JSON{
